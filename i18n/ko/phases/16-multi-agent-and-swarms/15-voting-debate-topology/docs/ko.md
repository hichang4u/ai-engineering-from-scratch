# 투표, 자기 일치, 토론 토폴로지

> 가장 저렴한 집합: 샘플 N 독립적 인 에이전트, 다수 투표. Wang et al. 2022 자기 일관성 한 모델 샘플 N 번으로 이것을했습니다. 다중 에이전트**heterogeneous**단일 문화에서 탈출하기 위한 요인  다른 모델, 다른 촉촉, 다른 온도, 다른 맥락. 다수 투표를 넘어 토론 토폴로지 문제는: MultiAgentBench (arXiv:2503.01935, ACL 2025) 은 별 / 연쇄 / 나무 / 그래프 조정을 평가하고 발견 **graph best for research**에지언트버스 (ICLR 2024) 는 두 가지 새로운 패턴을 기록하고 있습니다. 자원봉사자 행동과 준수 행동.

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 07 (Society of Mind and Debate), Phase 16 · 14 (Consensus and BFT)
**Time:** ~75 minutes

## 문제

토론은 정확성을 향상시킬 수 있습니다 (Du et al., arXiv:2305.14325). 또한 그것을 저하 할 수 있습니다. 토론이 도움이 되는 것은 네 가지 구조적 선택에 달려 있습니다.

1. 누가 누구와 이야기하는지 (토폴로지)
2. 얼마나 많은 공 (Du 2023: 공과 공무원 모두 독립적으로 중요합니다).
3. 에이전트가 이질적인지 (다양한 기본 모델은 단일농사를 깨고)
4. 적대적 목소리가 존재하는지 여부는 (철-관용과 정우-관용)

5명의 에이전트를 실행하고 투표하는 팀들은 하나의 에이전트를 상대하는 데 역전적이기도 합니다. 실패는 무작위적인 것이 아닙니다. 그들은 토폴로지와 이질성을 추적합니다. 이 교훈은 토폴로지 지도입니다.

## 개념

### 자기결합성, 단일 모델 기준

Wang et al. 2022 ("자동통합은 사상의 추론 체인을 향상시킵니다") 는 같은 모델을 온도 > 0에서 N 번 샘플링하고 추론 경로 답변에 대다수 투표를 했다. GSM8K: 단일 탐욕적인 디코드에 대한 N=40 샘플로 상당한 이득을 얻었다. 자동통합은 단일 에이전트 선구자다.

한계: 자기결합은 하나의 기본 모델을 사용합니다. 오류는 구조에 의해 상관관계가 있습니다. 모델이 체계적인 편향을 가지고 있다면, 모든 N 샘플이 그것을 공유합니다.

### 다중 대리자 투표, 이질적인 확장

N 샘플을 N * 다른* 에이전트로 교체하십시오. 다른 기본 모델 (클로드, GPT, Llama), 다른 명령어, 다른 도구 액세스. 이점은: 상관없는 오류. 비용은: 다른 에이전트는 다른 금액을 지불합니다.

2026년 heterogeneous debate의 정통적 명칭은**A-HMAD** 반대의적 이질적 다중 요원 토론. 보편적으로 채택되지 않았지만 논문에서는 "모노컬처 붕괴의 상관 오류를 줄이는 다양한 모델 토론"을 위해 용어를 사용합니다.

### 조율 세금 (MultiAgentBench)

멀티 에이전트 벤치 (MARBLE, ACL 2025, arXiv:2503.01935) 는 연구, 코딩 및 기획을 포함한 작업 스위트에 별, 체인, 트리, 그래프를 벤치마킹했습니다. 주요 측정 결과는:

- **Graph**토폴로지는 연구 작업에 승리합니다. 정보는 누구에게나 흐릅니다. 요인들이 서로를 비판할 수 있습니다.
- **Star**빠른 답변의 사실적인 작업에서 승리합니다. 허브는 필터링하고 통합됩니다.
- **Chain**단계적 파이프라인에서 승리 (단계 정비)
- **Coordination tax**그래프 토폴로지에서 4 대의 대상이 나타납니다. 벽 시계와 토큰 비용은 품질보다 빠르게 증가합니다.

4 대원 천장은 경험적, 근본적인 것이 아닙니다. 그것은 2026 LLM 컨텍스트 용량을 반영합니다. 각 대원의 컨텍스트는 동료의 출력으로 가득 차 있으며 모든 사람이 모든 사람을 볼 수있을 때 N+1 추가 대원의 한계 값이 떨어집니다.

### 다중 에이전트 토론 전략 ("우리는 미쳤어야 하는가?")

arXiv:2311.17371은 MAD 전략의 2023 조사입니다. 다른 사람들이 복사한 주요 연구결과: 자기 일치 (자립 샘플링 + 집합) 에 *구조적으로 유사한* MAD 변종은 동일한 예산을 사용할 때 종종 자기 일치성을 미치지 않습니다. 에이전트가 진정으로 이질적인 경우 MAD는 가장 도움이 되고 토론은 적대적 구조를 가지고 있습니다 (일 에이전트가 반발합니다).

### AgentVerse 등장 패턴

에이전트버스 (ICLR 2024, https://proceedings.iclr.cc/paper_files/paper/2024/file/578e65cdee35d00c708d4c64bce32971-Paper-Conference.pdf) 는 명시적인 설계 없이도 다중 요원 토론에서 나타나는 두 가지 행동을 기록합니다.

- **Volunteer.**에이전트가 도움 ("나는 다음 단계를 취할 수 있다") 를 요청하지 않고 제공 합니다. 유용합니다. 그것은 하위 작업에 가장 유능한 에이전트에 작업을 할당합니다.
- **Conformity.**에이전트는 비판자가 틀렸다고 하더라도 비판자와 일치하도록 자신의 입장을 조정합니다. 이것은 논쟁과 같은 '심화' (강좌 14) 이다.

합의까지의 논쟁은 협조를 통해 괴롭힘을 당하는 사람들을 보상합니다.

### 심사위원 방법

시빌 프레임워크 (민스키-LLM 문학에서 인용) 는 "심사위원회"를 공식화합니다. 각 단계에서 투표함으로써 답변을 정비하는 소규모 전문 요원입니다. 단순한 과반수의 투표와 달리, 심사위원회는 역할을 합니다. 한 요원이 교차고시를 수행하고, 한 명이 맥락을 제공하며, 한 명이 유력성을 점수합니다. 심사위원회 방법은 단순한 투표 (싼, 단일 문화 유력) 와 완전한 MAD (비용, 적합성 유력) 사이 중점입니다.

### 토론과 투표가 지배적인 경우

- 이 질문은 기본 진실 (사실, 수학, 코드 행동) 을 가지고 있습니다. 투표의 공렴은 의미 있습니다.
- 에이전트는 다양한 소스나 도구에 접근할 수 있습니다 (다분별성이 가능합니다).
- 라운드는 제한되어 있습니다 (2-3 전형적인) 그리고 별도의 판사 또는 검증자가 있습니다.
- 예산은 3-5명의 에이전트를 허용하고, 5-7명의 그래프 토폴로지를 넘어, 조율 세금이 지배적이다.

### 토론과 투표가 아프면

- 의문은 의견의 형태입니다. 에이전트는 가장 확신이 있는 답변을 합쳐서 가장 정확하지 않은 답변을 합쳐줍니다.
- 모든 에이전트는 기본 모델을 공유합니다. 단일 문화는 합의가 무의미합니다.
- 은 무한합니다. 항상 일치가 승리합니다.
- N=5에서 자기결합성을 가진 단일 대리인은 저렴하고 정확합니다.

## 건설 해

`code/main.py`이 도구는

- `run_star(agents, hub, question)` 각 노동자, 전체에 대한 조사
- `run_chain(agents, question)` 순서적 정비
- `run_tree(root, children, question)` 깊이-2 집합과 함께 계층적.
- `run_graph(agents, question, rounds)` 모든 것에 대한 논쟁, 제한된 라운드.
- 각 에이전트가 `error_bias`체계적인 잘못을 나타냅니다.
- 각 토폴로지를 N=3, 5, 7에서 실행하고 보고 (정확성, total_tokens, wallclock_simulated) 하는 측정 띠.

실행:

```
python3 code/main.py
```

예상 출력: 토폴로지 × N → (정확함, 토큰, 지연) 테이블. 그래프는 연구 방식의 작업에서 N=3-5에서 승리하며, 별은 빠른 사실적인 작업에서 승리하며, 그래프는 N=7에서 조율 세금을 보여줍니다 (연연은 정확보다 더 빨리 부풀어진다).

| Self-consistency | "Sample N times, vote" | Wang 2022. Single model, N temperature>0 samples, majority vote on reasoning paths. |
| Heterogeneity | "Different models" | Ensemble of different base models or prompt families. Breaks monoculture. |
| MAD | "Multi-agent debate" | Generic term for agents exchanging critiques over rounds. See Du 2023. |
| A-HMAD | "Adversarial Heterogeneous MAD" | MAD variant emphasizing different models + adversarial structure. |
| Topology | "Who talks to whom" | Star, chain, tree, graph. Determines information flow. |
| Coordination tax | "Diminishing returns" | Above ~4 agents on graph, cost grows faster than quality. |
| Volunteer behavior | "Unprompted help" | AgentVerse emergent pattern: an agent offers to take a step. |
| Conformity behavior | "Agreement under pressure" | AgentVerse emergent pattern: an agent aligns with a critic. |
| Jury | "Small specialized panel" | Sibyl-style ensemble with roles (examiner, context, scorer). |
