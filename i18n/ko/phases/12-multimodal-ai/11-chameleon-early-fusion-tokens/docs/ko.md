# 멜레온과 초기 융합 토큰만 있는 멀티모델

> 지금까지 우리가 본 모든 VLM는 이미지와 텍스트를 분리합니다. 시각 토큰은 비전 코더에서 나오고 프로젝터로 흘러나가고 LLM 내부의 텍스트를 만나게 됩니다. 시각과 텍스트의 어휘는 결코 겹치지 않습니다. 카멜레온 (메타, 2024년 5월) 은 물었습니다. 공유된 어휘에서 나온 별도의 토큰의 연속으로 이미지를 변환하는 VQ-VAE를 훈련시킵니다. 모든 멀티모달 문서는 이제 하나의 순서  텍스트 토큰과 이미지 토큰이 겹쳐져 있습니다. 부작용: 모델은 하나의 추론 호출에서 혼합 모다리티 출력을 생성할 수 있습니다. 이 수업은 초기 융합 논문을 읽고 끝까지 장난감 버전을 만듭니다.

## 문제

어댑터 기반 VLM (LLaVA, BLIP-2, Qwen-VL) 는 텍스트와 이미지를 두 가지 다른 것으로 취급합니다. 텍스트 토큰은 `embed(text_token)`; 이미지가 통과합니다 `visual_encoder(image) → projector → ... pseudo_tokens`모델은 2개의 입력 경로를 가지고 있습니다.

세 가지 결과:

1. LLM는 이미지를 소비할 수 있고, 발사할 수 없습니다. 출력은 텍스트만입니다.
2. 혼합 모달리티 문서 (문서와 이미지의 대변) 은 어색합니다.
3. 배포 부합: 시각 토큰과 텍스트 토큰은 숨겨진 공간의 다른 영역에서 살고 있으며, 미묘한 조율 문제를 발생시킵니다.

멜레온은 이 전제를 거부합니다. 이미지는 공유된 어휘에서 나온 단독 토큰의 순서입니다. 서로 얽힌 문서에 모델을 훈련시켜, 한 손실, 한 자동 퇴행 디코더를 해제하고, 혼합 모달리티 생성을 무료로 해제합니다.

## 개념

### VQ-VAE는 이미지 토큰화로서

토케니저는 벡터 양자 변동자동화 코드입니다.

- 코더: CNN + ViT, 공간적 특징 지도에 이미지를 지도하는, 예를 들어 dim 256의 32x32 특징을 나타냅니다.
- 코드북: K 벡터의 학습된 어휘 (Chameleon은 8192을 사용합니다), 또한 dim 256.
- 양자화: 각 공간적 특징에 대해 L2 거리에 따라 가장 가까운 코드북 항목을 검색하십시오. 연속적인 특징을 정수 지표로 교체하십시오.
- 디코더: CNN는 양자화된 기능을 픽셀로 되돌려줍니다.

훈련: VAE 재구성 손실 + 약속 손실 + 코드북 손실. 코드북 인덱스는 이미지의 분별 알파벳을 형성합니다.

멜레온: 한 이미지는 32*32 = 1024 토큰으로 되어 8192의 어휘에서 추출된다. 텍스트 토큰으로 연결된다 (LLM의 BPE 어휘에서, 예를 들어 32000). 최종 어휘: 40192. 트랜스포머는 하나의 순서, 하나의 손실을 볼 수 있다.

### 공유된 어휘

샤멜레온의 어휘는 텍스트 토큰, 이미지 토큰, 모달리티 분리자를 결합한다. 각 토큰은 단일 ID를 가지고 있다. 입력 임베디션 레이어는 모든 ID를 D-dim 숨겨진 벡터로 지도한다. 출력 투사 지도는 음성 로그티에 숨겨져 있다. 소프트맥스는 다음 토큰을 선택한다.

분리기들은 중요해요`<image>`그리고`</image>`태그는 이미지 로큰 순서로 묶여 있습니다. 생성 시점에, 모델이 발광하면`<image>`, 하류 소프트웨어 다음 1024 토큰은 VQ 지표로 픽셀 렌더링을 위해 디코더로 전송합니다.

### 혼합 모다리티 생산

인퍼런스는 공유된 어휘에서 다음 로큰 예측입니다. 예제 提示: "고양이를 그려 설명하십시오".

```
<image> 4821 1029 2891 ... (1024 image tokens) </image>
The cat is orange, sitting on a windowsill...
```

모델은 순서를 자율적으로 선택합니다. 그것은 이미지, 텍스트, 텍스트, 이미지 또는 인터레베이스를 생성할 수 있습니다. 동일한 디코더, 동일한 손실.

어댑터 VLM와 비교해 보면, 생성 방식은 텍스트만 사용된다.

### 훈련 안정성  QK-Norm, 중퇴, 레이어Norm 주문

조기 융합 훈련은 규모가 불안정합니다. 멜레온의 논문에는 세 가지 트릭이 있습니다.

- QK-Norm. 점 제품 이전에 관심 내부에 질의와 핵심 투구에 LayerNorm을 적용합니다. 깊이에서 로그이트 규모 폭발을 방지합니다. 2024 이후 여러 대형 모델에서 사용됩니다.
- 분해 배치. 모든 잔류 추가 후 분해, 관심과 MLP 후에만 아닙니다. 이미지 토큰의 기하급수가 지배할 때 더 많은 규칙화가 필요합니다.
- 레이어노름 순서: 잔류 지부 (표준) 에 전-LN, 그리고 마지막 블록의 스프 연결에 추가 LN. 최종 층 기하급수 흐름을 안정시킵니다.

이 트릭이 없으면 34B-param 멜레온 훈련은 여러 점에서 분할되어 있습니다.

### 토큰 시너지의 재건 천장

VQ-VAE는 손실이 있다. 512x512 이미지당 8192개의 코드북 입력과 1024개의 토큰으로 재구성 PSNR는 26-28 dB 정도를 차지한다. 이것은 인식 가능한 이미지 유전자에 충분하지만 연속 공간 전파보다 눈에 띄게 더 나빠진다 (Stable Diffusion 3는 32+ dB를 달성한다).

토큰화기는 병목이다. 더 나은 토큰화 (MAGVIT-v2, IBQ, SBER-MoVQGAN) 는 천장을 높인다. Emu3 (강좌 12.12) 는 더 나은 토큰화기를 통해서만 SDXL 품질의 생성을 달성합니다.

### 멜레온 vs BLIP-2 / LLaVA

멜레온 (초기의 융합, 공유 어휘):
- 한 손실, 한 디코더
- 혼합 모다리티 출력을 생성합니다.
- 토케니저는 품질의 천장입니다.
- 값 비싼: 추론 경로에서 생성된 이미지당 VQ-VAE 디코더

BLIP-2 / LLaVA (오후 핵융합, 별도의 탑):
- 비전, 문자만 보내야 돼
- 재교육된 LLM를 재사용합니다.
- 이해의 단점이 없습니다.
- 저렴: 단일 전진 패스

작업에 따라 선택하세요. 이미지 생성, 샤멜레온 가족만 필요하다면 이해만 하면, 어댑터-VLM는 더 간단하고, 더 훈련된 컴퓨팅을 재사용합니다.

### 후유와 AnyGPT

후유 (Adept, 2023) 는 이와 관련된 접근법입니다. 별도의 비전 코더를 완전히 건너뛰고, 토큰이 아닌 토큰이 아닌 LLM의 입력 프로젝션을 통해 원료 이미지 패치를 공급합니다. 샤멜레온보다 간단하게 공유 된 음성 출력 생성을 잃습니다.

AnyGPT (Zhan et al., 2024) 은 Chameleon 을 네 가지 방법 으로 확장 합니다. 텍스트, 이미지, 연설, 음악. 각각의 VQ-VAE 트릭, 공유 트랜스포머. 모든 세대. 12.16 수업에서 더 많이 다루었습니다.

5. 장난감 디코더를 확장하여 텍스트 전용 명령어에서 혼합 모달리티 응답을 내보내십시오. 모델이 얼마나 자주 이미지를 먼저 선택하는지 측정합니다.

## 주요 용어

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Early fusion | "Unified tokens" | Images converted to discrete tokens sharing the transformer's vocabulary from step one |
| VQ-VAE | "Image tokenizer" | CNN + ViT + codebook that maps images to integer indices the transformer can predict |
| Shared vocabulary | "One dictionary" | A single token ID space covering text + image + modality separators |
| QK-Norm | "Attention stabilizer" | LayerNorm applied to query and key before their dot product, prevents norm blowup |
| Mixed-modality generation | "Text + image output" | Inference that autonomously produces interleaved text and image tokens in one pass |
| Codebook size | "K entries" | Number of discrete vectors the VQ-VAE can quantize to; trades compression for fidelity |
| Tokenizer ceiling | "Reconstruction limit" | Best PSNR achievable by decoding VQ tokens; bounds the model's image quality |
