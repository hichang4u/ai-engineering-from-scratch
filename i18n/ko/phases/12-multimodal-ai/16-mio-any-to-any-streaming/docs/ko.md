# MIO 및 모든 스트리밍 멀티모달 모델

> GPT-4o는 대부분의 개방형 모델들이 복제할 수 없는 제품을 선보이고 있습니다. 음성들을 듣고 동영상을 보고 실시간으로 다시 이야기하는 에이전트입니다. 2024년 말까지 개방형 생태계 답은 MIO (Wang et al., 2024년 9월) 이었다. MIO는 텍스트, 이미지, 음성, 음악을 토큰화하고, 상호간접한 순서들을 통해 하나의 인과변화자를 훈련시키고, 어떤 모달리티를 어떤 모달리티로든 생성합니다. AnyGPT (Zhan et al., 2024년 2월) 은 개념의 증명이었으며 MIO는 확장; Unified-IO 2 (Allen AI, 2023년 12월) 는 비전 + 액션 지형의 사촌이다. 이 수업은 어떤 패턴으로든 4개의 토큰, 하나의 트랜스포머, 스트리밍 친화적인 디코드를 읽습니다.

**Type:** Learn
**Languages:** Python (stdlib, four-modality token allocator + streaming decode loop)
**Prerequisites:** Phase 12 · 11 (Chameleon), Phase 6 (Speech and Audio)
**Time:** ~120 minutes

## 학습 목표

- 텍스트, 이미지, 음성, 음악 토큰을 충돌 없이 저장할 수 있는 공유 어휘를 설계하십시오.
- 압축 + 재건 상환에 대해 SEED-Tokenizer (사진) 과 SpeechTokenizer 잔류-VQ (소설) 을 비교하십시오.
- 어떤 세대에서 어떤 세대까지 발전시키는 4단계 교육과정을 설명해 주세요.
- 3개의 오픈-to-any 레시피와 그 주요 타협을 명명하라: MIO, AnyGPT, Unified-IO 2.

## 문제

통합 멀티모달 모델은 쉽게 주장하고 규모로 구축하기 어렵다. 2024년까지 대부분의 "누구나 어느 누구" 시스템은 파이프라인을 통해 이루어졌습니다. 비전 모델 → 텍스트 표현 → 음성 모델 → 오디오. 각 홉은 정보를 잃어 지연을 추가하고 훈련을 복잡하게 만듭니다. GPT-4o의 데모 비디오는 단일 모델 대안을 보여 준 후속 반응; 오픈 시스템은 몇 달이 뒤따랐다.

엔지니어링 과제:

- 모든 모다리티에 대한 토큰화가 존재해야 하며, 재구성하기에 충분한 손실 없이 압축하고, 트랜스포머가 소비할 수 있는 속도로 토큰을 생산해야 합니다.
- 단일 어휘는 텍스트 (32k+), 이미지 (16k+), 연설 (4k+), 음악 (8k+) 에 공간을 할당해야 합니다. 최소 40만 이상의 항목이 필요합니다.
- 교육 데이터는 모든 입력-출력 쌍 ( 텍스트→ 이미지, 이미지→언어, 연설→ 이미지, 등) 를 포함해야 합니다.
- 인퍼런스는 대화 지연 (<500ms 시간-처음 오디오-바이트) 에 대한 출력 토큰을 충분히 빠르게 스트리밍해야 합니다.

## 개념

### 네 가지 방식에 대한 4 개의 토큰

MIO의 토큰 스택:

- 텍스트: 표준 BPE, 음성 ~32000.
- 이미지: SEED-Tokenizer (2023)  분단 코드북, 4096 항목, 이미지당 32x32 토큰을 가진 양자화된 VAE
- 연설: 스피치토케니저 잔류-VQ (2023) 는 16kHz 파형 형태를 8개의 계층 코드북으로 암호화합니다. 첫 번째 레벨은 거친 내용이며, 후속 레벨은 프로소디와 스피커 아이덴티티를 추가합니다.
- 음악: 비슷한 잔재-VQ (메타의 MusicGen / Encodec 가족), 4-8 코드북.

각 모달리티는 정수 토큰을 생성합니다. 토큰은 공유 된 어휘에서 분리된 ID 범위를 얻습니다.

```
text:   0..31999
image:  32000..36095  (4096 image tokens)
speech: 36096..40191  (4096 speech base tokens, plus residual layers)
music:  40192..48383  (8192 music tokens)
sep:    48384..48390  (<image>, <speech>, <music>, </...>, etc.)
```

전체: ~ 48k 어휘. 입력 임베디션과 출력 투사 전체에 걸쳐 있습니다.

### 스트리밍 디코드

음성 생성에는 잔류-VQ를 사용합니다. 트랜스포머는 기본 (층 0) 음성 토큰을 예측하고, 병렬 디코딩된 잔류 양자기는 다음 층을 예측합니다. 각 층 0 토큰은 16kHz에서 약 50ms의 오디오입니다.

스트리밍 패턴:

1. 사용자는 마이크로 이야기합니다. 실시간 오디오 토큰이 50ms마다 음성 토큰을 발송합니다.
2. MIO는 도큰이 도착할 때 소비한다 (단순한 사전충전 + 증가적인 전향).
3. 출력 토큰은 생성된 대로 스트리밍됩니다. 평행 음성 디코더는 ~50-150ms 지연으로 오디오 샘플로 변환합니다.
4. 시간-처음 오디오 바이트: MIO 종이에 ~300-500ms, GPT-4o ~250ms에 가까워집니다.

미니 오미 (arXiv:2408.16725), GLM-4-보이스 (arXiv:2412.02612), 그리고 모시 (arXiv:2410.00037) 는 보조 스트리밍 음성-LLM 디자인이다. 모시 특히 단일 GPU에서 160ms 반여행을 달성합니다.

### 4단계 교육과정

MIO의 교육 교육과정:

1. 1단계  조율. 대규모 모다리티-쌍 코퍼스: 텍스트 이미지, 텍스트 연설, 텍스트 음악. 각 쌍은 자신의 토큰 어휘 세그먼트를 사용합니다. 공유 어휘를 훈련합니다.
2. 2단계                                                                                                                                                                                                                                                              
3. 3단계  음성 향상. 텍스트 능력을 잃지 않고 음성 품질을 높이기 위해 추가 오디오 데이터.
4. 4단계  SFT. 모다리들 간 교육 조정: VQA, 캡션, 서술, 연설-언어 대화.

단계가 빠지면 특정 능력을 떨어뜨립니다. 2 단계를 건너뛰고 모델은 크로스 모다리티 컨텍스트를 잃습니다. 3 단계를 건너뛰고 언어는 좋지 않습니다.

### 시각적 사고의 연쇄

MIO는 시각적 사고 체인을 도입합니다. 모델은 중간 이미지 토큰을 추론 단계로 발사합니다. "고양이 나무에 올라가는가 있습니까?" 모델은:

1. 방출`<image>`시나 (인पुट 이미지나 스케치) 를 렌더링하는 토큰
2. 스케치를 분석하는 텍스트를 발송합니다.
3. 최종 답을 내놓습니다.

렌더링 중간 이미지는 스크래치판으로 작용한다. 벤치마크는 공간적 추론 작업에 개선된다. 이 아이디어는 텍스트 추론을 위한 사상의 연쇄를 반영한다.

### 경쟁자

- AnyGPT (arXiv:2402.12226): 4 가지 방식 ( 텍스트, 이미지, 연설, 음악), 유사한 디자인.
- 통일된-IO 2 (arXiv:2312.17172): 시각 행동 출력, 깊이, 정상을 추가합니다. 더 많은 작업 다양성, 더 작은 규모.
- NExT-GPT (arXiv:2309.05519): LLM + 모달리티 특화된 전파 디코더. 단일 모델 접근 방식이 아닙니다.
- CoDi (arXiv:2305.11846): 합성 디스포지션; 공유된 잠자리를 통해 어느 쪽으로나.

MIO는 순수 토큰 (pure token) 에 가장 가깝다. AnyGPT는 개념적 조상이다.

### 지연 예산

대화용 제품에서는 각 구성 요소의 지연이 중요합니다.

- 마이크에서 오디오 토큰: ~50ms.
- 사전 채용 (오디오 토큰 + 역사): ~ 8B 모델에서 100ms.
- 첫 출력 토큰: ~50ms.
- 평행 잔류-VQ + 음성 디코더: ~ 100-150ms.

전체 시간-처음 오디오 바이트: ~300ms 최소. GPT-4o 주장 ~250ms. 모시 주장 160ms. MIO / AnyGPT는 공공 벤치마크에 따라 400-600ms 범위에서 있습니다.

## 운동

1. 제품에서는 음성 입력과 음성 출력을 받아내죠. 엔드-투-엔드 지연 예산은 무엇일까요? 시간을 보내는 구성 요소들을 나열하세요.

2. 스피치토키니저 잔류-VQ는 8개의 코드북을 사용한다. 잔류 레벨을 병렬적으로 디코딩하는 것이 왜 필요한지 (열렬에 비해) 그리고 그것이 가져오는 지연성 절약을 제안한다.

3. 문장에는 32k 텍스트 + 4k 이미지 + 4k 음성이 있습니다. 8k 음악과 ~10개의 분리기를 추가하십시오. 숨겨진 dim 4096에서 임베디션 매트릭스 매개 변수 비용은 무엇입니까?

4. 시각적 사고의 연쇄는 중간적인 이미지를 방출합니다. 어떤 종류의 질문들이 유익합니까? 어떤 종류의 질문들이 추가적인 토큰에 의해 손상됩니다?

5. 모시 (arXiv:2410.00037) 를 읽어 보십시오. "내적 단언" 기법을 설명하고 MIO의 시선적 사고와 비교해 보십시오.

## 주요 용어

| Term | What people say | What it actually means |
|------|-----------------|------------------------|
| Any-to-any | "Multimodal in/out" | A single model that accepts and emits text, image, speech, and music in any direction |
| Residual-VQ | "Speech tokenizer stack" | Multi-codebook tokenization where each layer adds information; base layer is content, later layers are prosody |
| SEED-Tokenizer | "Image codes" | Discrete image tokenizer with 4096-entry codebook used by MIO |
| Chain-of-visual-thought | "Visual scratchpad" | The model generates an intermediate image as a reasoning step before its final answer |
| Time-to-first-audio-byte | "TTFAB" | Latency from user voice to first audio output; <500ms for conversational feel |
| Four-stage curriculum | "Training recipe" | Alignment -> interleaved -> speech-enhanced -> SFT, in that order |
